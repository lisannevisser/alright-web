# alright — website

Homepage, Support and Privacy Policy pages for the [alright](https://apps.apple.com) app (al/right).
Support and Privacy exist because Apple requires a working Support URL and Privacy Policy URL for
every app (Guideline 1.5 and 5.1.1(i)).

Plain static HTML, no build step. Served via GitHub Pages.

- `/` — Homepage (EN), `/de/` (DE)
- `/support/` — Support page (EN), `/support/de/` (DE)
- `/privacy/` — Privacy Policy (EN), `/privacy/de/` (DE)

Note: Support used to live at `/`. When the homepage goes live, the Support URL in App Store Connect
has to be changed to `/support/`, otherwise people coming from the App Store land on the marketing page.

The whole site is `noindex` for now.
