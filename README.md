# alright — website

Support and Privacy Policy pages for the [alright](https://apps.apple.com) app (al/right), required for App Store submission (Guideline 1.5 and 5.1.1(i)).

Plain static HTML, no build step. Served via GitHub Pages.

- `/` — Support page (EN + DE)
- `/privacy/` — Privacy Policy (EN + DE)

This is not the marketing site — that's a later, separate build. These two pages exist because Apple requires a working Support URL and Privacy Policy URL for every app.
